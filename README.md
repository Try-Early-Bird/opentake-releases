# Opentake downloads

Desktop installers and release notes for [Opentake](https://github.com/Try-Early-Bird/opentake).

[Download the latest release](https://github.com/Try-Early-Bird/opentake-releases/releases) (macOS 13 or later, Apple silicon and Intel).

This repository contains distribution assets only. The source code, issues and
security policy live in [Try-Early-Bird/opentake](https://github.com/Try-Early-Bird/opentake).
